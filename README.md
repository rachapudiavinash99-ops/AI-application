# AI Application

A full-stack AI-powered application built with FastAPI and React.
This repository was developed incrementally following strict engineering practices.

## Features
- Secure Authentication (JWT)
- Topic-based AI Task execution (Local Mock Provider for development)
- Full-stack React + TypeScript frontend
- SQLAlchemy models and SQLite database
- Docker Compose development setup

## Quick Start
1. `docker-compose up --build`
2. Backend is at `http://localhost:8000`
3. Frontend is at `http://localhost:3000`
